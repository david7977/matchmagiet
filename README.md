# Rotador de Puestos (CSV para Excel)

Aplicación web simple (HTML/CSS/JS) para crear rotaciones justas de usuarios:

- Mantiene el orden de rotación en días hábiles (lunes a viernes), respetando la continuidad de viernes a lunes.
- Permite agregar y quitar usuarios fácilmente.
- Permite elegir entre 1, 2 o 3 puestos activos por día.
- Genera una vista previa y exporta un archivo CSV listo para abrir en Excel.

## Uso

1. Abre `index.html` en tu navegador.
2. Agrega o quita usuarios de la lista.
3. Elige fecha de inicio, cantidad de semanas y puestos activos.
4. Haz clic en **Generar calendario**.
5. Haz clic en **Exportar CSV (Excel)** para descargar el archivo.
